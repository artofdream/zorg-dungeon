## Phase 3 — Portals, gold & tolls (this PR)

Started from `main` @ `2217dd5` (Phase 2 PR #8); later merged current `main` so the journal keeps the ops CD notes above. Producer does not merge (S7).

- **[[FR-15]] Portal `P(n,f)`** in `@zorg/engine`: i-th entry into that P (i ≤ n) teleports to the first cell of the f(i)-th-most-recent visit; overshoot → waiting room + respawn. `f` accepts a constant, `i->…`, or corpus maps like `x↦7x-6`. History used by `f(i)` is visits *before* this portal entry. Evidence: `packages/engine/src/portals.test.ts`.
- **[[FR-16]] Gold `O(x)`**: first entrant takes the pile; death reattaches the FIFO purse to the death room (that room now holds an O pile). Pickup runs before D / Z / P / cell effects. Evidence: `packages/engine/src/gold.test.ts`.
- **[[FR-17]] Toll `T(x,elem)`**: dark cells use the same fire/water/ice/poison tick as [[FR-14]]; light cells charge the oldest x gold (refunded to source rooms). Unpaid light is not a voluntary step; an ice slide onto one is instant death. Default T tile: interior 3×3 dark, hatches light (official art still not in the extract — tests paint cells). Dark/light ≡ open for [[FR-6]]. Evidence: `packages/engine/src/tolls.test.ts`.
- Warrior / Elf still own pathing. When O/T gold is on the map, Warrior's shortest path can pick up a pile so a later light cell is payable. Portals stay entry effects (not a planned shortcut graph). Scheduler still owns A / Z / D / E, Warrior, Elf, and single-active-hero order.
- Ledger: only [[FR-15]], [[FR-16]], [[FR-17]] → `Simulated`. [[NFR-1]] / [[NFR-10]] stay Unknown. [[FR-18]] C, Gunner duration, [[FR-4]], N11/N18 quarantine, spells, Mechanic / Gunner / Princess, mirrors unchanged.
- Thin Maker copy only (gold count in the playback line).

### Assumptions a reviewer can check

- Portal `f(i)` looks up history **excluding** the current P entry (so `P(1, 1)` bounces to the previous room, matching “1st-most-recent visit”).
- A visit's first cell is the cell the hero occupied when that visit began (spawn = room center).
- Pickup pre-empts other entry effects as **ordering** (gold first, then D/Z/P), not as skipping them.
- Warrior planning ignores death on a later unpaid light the same way it ignores lethal D; voluntary unpaid lights stay blocked like water.

Selection meta-dispatches only the four spells that have a documented variant. Evidence: `packages/engine/src/spells.test.ts`.
- Scheduler still owns A / Z / D / E / P / O / T, Warrior, Elf, and single-active-hero order. Casts plug into that run via `castSpell` / `simulate({ castScript })`; they do not fork it. Sleep leaves the hero active (not stuck) so later heroes stay blocked until [[FR-41]] Wake or an HP change.
- Move / Swap re-check [[FR-6]] edges ([[FR-38]]) and reject the cast (no consume) on mismatch. Contents (heroes, visit first-cells, poison marks) travel with the room. Spell `Teleport` reuses portal visit lookup; it relocates, it does not invent a new room-entry.
- Ledger: only [[FR-32]]–[[FR-42]] → `Simulated`. [[NFR-1]] / [[NFR-10]] stay Unknown. Mechanic / Gunner / Princess, mirrors, [[FR-18]] C, Gunner duration, [[FR-4]], N11/N18 quarantine unchanged.
- Thin Maker copy: Phase 4 demo is A / Z / D + `Attack(3)` with a spell tray during playback.

### Assumptions a reviewer can check

- A cast window opens only after `stepCount > 0` and never while `midAction` is set (one `stepRun` is one completed action, including an in-step portal hop).
- Unselected `Attack` hits every living hero, including those still in the waiting room; Selection is how you hit a subset.
- `Teleport(n)` uses the full visit list (`n=1` is the current room). Overshoot → waiting room, same as [[FR-15]].
- Sleep / Wake / Banality have no Selection variant in the spec — wrapping them is illegal and consumes nothing.
- Move destinations must be empty *now*; simultaneous Selection Move does not treat a vacated cell as empty.

## Phase 5 — Mechanic, Gunner + Shell, Princess (this PR)

Started from `main` @ `6dc0191` (Phase 4 Spellbook PR #14). Producer does not merge (S7).

- **[[FR-24]] Mechanic(x, dict)** in `@zorg/engine`: shortest path to the weight target (usually Z), ignoring HP, using shove power; then fewest unjustified shoves; then prefer using power; then up → right → down → left. From a listed room it shoves that room (contents travel) one adjacent empty cell; `dict[roomType]` is that instance's remaining budget. FR-6 is not a shove gate. Evidence: `packages/engine/src/mechanic.test.ts`.
- **[[FR-22]] Gunner(x, c[, dur])** 2-arg path/fire: fire a useful Shell soonest, then HP-preserving shortest path factoring shots, up to `c` shots (`inf` = no cap), Warrior tie order. **S3: duration is parse-accepted and stored; it is never read.** No shot-lifetime, fire-rate, or "infinite duration cannot fire" rule is encoded. Evidence: `packages/engine/src/gunner.test.ts`.
- **[[FR-23]] Shell**: instant cardinal projectile; stops at a wall or the dungeon edge; clears elemental cells; clears D-room monsters (that D no longer deals damage); 2 damage to every hero crossed; other action pauses for the Gunner's fire action. **Z-monster clear is deferred** — [[FR-12]] still holds after a Shell crosses Z (NFR-8: do not invent "kill Zorg"). Evidence: `packages/engine/src/gunner.test.ts`.
- **[[FR-25]] Princess weight-pull**: perceived weight = average of the viewer's default (own dict, else `{Z:1}`) and every *other* princess's pull `b` standing in that room. Every hero is subject to this pull; then HP-preserving shortest path to the highest-weight reachable room (Warrior still ignores HP). Evidence: `packages/engine/src/princess.test.ts`.
- Scheduler still owns A / Z / D / E / P / O / T, spells, and single-active-hero order. New heroes plug into `chooseStep` / `stepRun`; they do not fork it.
- Ledger: only [[FR-22]]–[[FR-25]] → `Simulated`. [[NFR-1]] / [[NFR-10]] stay Unknown. [[FR-18]] C, Gunner duration, [[FR-4]], N11/N18 quarantine, mirrors unchanged.
- Thin Maker copy: lede mentions Phase 5; demo stays A / Z / D + Warrior + `Attack(3)`.

### Assumptions a reviewer can check

- A Mechanic shove is **one** adjacent empty grid cell; budget is per placed room, initialized from `dict[type]` (or `dict[roomId]` if authored that way). "Unjustified" = a shove that does not strictly decrease remaining walk-distance to the target.
- Gunner "useful" fire = a Shell that would clear at least one elemental cell or a still-live D monster. Duration, including `inf`, does not change that.
- Shell does **not** neutralize Z. Entering Z is still an instant loss.
- Princess pull uses living, spawned princesses only. A waiting-room or dead princess does not add pull. The viewer does not count their own pull.
- When no princess is on the board and defaults stay `{Z:1}`, Warrior / Elf pathing is unchanged.

## Phase 6 — Mirror worlds & solvability search (this PR)

Started from `main` @ `7d3cba6` (Phase 5 PR #15). Producer does not merge (S7).

- **[[FR-9]] Mirror substitution** in `@zorg/engine`: one shared constructed room graph; the Nth declaration-order room is swapped 1:1 for each mirror world's own list. Positions / orientations / authored tiles stay; ids and defs are reminted from the mirror list. Each world keeps its own heroes and spells. Loader accepts `Mirror:` / `M':` / `Monde miroir:` blocks; `validateLevel` rejects a length mismatch. Evidence: `packages/engine/src/mirrors.test.ts`.
- **[[FR-45]] Sequential resolve** : worlds run normal → M′ → M″. Each world retires once idle (stalemate / nothing changes) or once its Z is reached, then the next world starts. A world whose heroes all die is recorded as `cleared` (terminal, not a [[FR-43]] claim). Evidence: `packages/engine/src/mirrors.test.ts`.
- **[[FR-46]] Solvability** : `checkSolvability(level, layout)` searches for a spell-cast sequence that lets that world's heroes all die before Z. Empty Φ is allowed (heroes dying on the map). Evidence: `packages/engine/src/solvability.test.ts`.
- **[[NFR-4]] Bounded search** : BFS over FR-33 windows; each spell still one-time ([[FR-32]]). Hard caps (`maxNodes` 512, `maxBranch` 8, `maxSteps` 256). Candidates are linear in unused spells × (heroes + rooms). Selection subsets and an infinite empty grid are not enumerated. `budget` means the cap fired before exhaustion — that is not a proof of impossibility. Evidence: `packages/engine/src/solvability.test.ts`.
- Ledger: only [[FR-9]], [[FR-45]], [[FR-46]], [[NFR-4]] → `Simulated`. [[FR-43]] / [[FR-44]] stay Unknown (no cross-world win evaluator, no constraint/bonus interpreter). [[NFR-1]] / [[NFR-10]] stay Unknown. [[FR-18]] C, Gunner duration, [[FR-4]], N11/N18 quarantine unchanged.
- Thin Maker copy: lede mentions Phase 6; demo stays A / Z / D + Warrior + `Attack(3)`.

### Assumptions a reviewer can check

- Declaration order is `flattenRooms` / `enumerateSuppliedRooms` order, not type-name order. A mirror that lists `D, A, Z` against a base `A, Z, D` moves those defs onto the constructed cells in that Nth-slot pairing.
- Worlds are resolved **sequentially**, not in lockstep. A Z entry retires **that** world ([[FR-45]]); it is not promoted to a whole-level loss ([[FR-43]]).
- `not_solvable` is exhaustion of the **bounded candidate model** (NFR-4), complete for Attack/Teleport-only bags, not a proof over Selection subsets or arbitrary Move destinations.
- Move auto-candidates are cardinal empty cells touching current occupancy. Selection is never an auto-candidate.
