# 2026-11-18

## Repo skills for the Godot loop

Four recipes that kept being copied into PR bodies now have a `SKILL.md`
each under `.cursor/skills/`:

- `godot-headless-verify` — golden regeneration, `parity_test.gd`,
  `level_smoke_test.gd`, and `web_boot_check.mjs`, with the exit codes
  the `godot` workflow reads.
- `debug-apk-reinstall` — download `zorg-godot-android-debug-apk`, and
  `adb uninstall link.artof.zorg` only after a signature mismatch.
- `godot-cosmetic-lights` — extra lights stay in
  `apps/godot/levels/visual-lights.json`.
- `zorg-pr` — branch `agent/grok/<task>`, small PRs, parity green and
  the debug APK artifact when Godot or the engine changes. The author
  leaves merge and `production` deploy approval to the owner.

[[AGENTS]] §9 is the matrix (Skill, Scope, Why, What). [[SKILL_MATRIX]]
points at the same files. [[LEARNINGS-godot]] points at them too.
