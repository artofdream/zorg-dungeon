# ADR-0007: Sustainable FR/EN i18n (display-only)

- Status: Accepted
- Date: 2026-09-13

## Context

The Maker and knowledge companions ship English-first copy for kids (~8) and
helpers. A French audience needs the same surfaces without rewriting engine
tokens, inventing unavailable rules, or forking GAME_SPEC. Prior notes said
“no i18n rewrite” for hatch copy ([[NFR-7]]); that was scope deferral, not a
ban on a catalog-based display layer.

Constraints that still bind:

- [[GAME_SPEC]] English IDs and engine tokens (`A` / `Z` / `D` / …, hero type
  names in data) stay the legal voice. Companions never override the spec.
- Do **not** invent room `C`, Gunner shot-duration, or [[FR-4]] contract
  gating ([[NFR-8]] fail-closed). Honesty disclosure may name those gaps;
  playable copy must not claim they are built.
- Phase C (bilingual honesty ledger / skills matrix / full GAME_SPEC) is out
  of scope for this decision.

## Decision

1. **Message catalogs** under `apps/web/src/locales/{en,fr}.ts` hold every
   user-facing Maker string. EN keys are the source of truth; FR is a complete
   parallel catalog. Display-only: translate words players see (Start/Départ,
   Exit/Sortie, Difficulty/Difficulté), keep engine tokens and FR/NFR IDs as
   data.
2. **Tiny `t(key)` + locale context** in `apps/web/src/i18n/`. Default locale
   is EN. No React Router in this slice — URL strategy is **`?lang=fr`**
   (canonical), with `document.documentElement.lang`, `localStorage` key
   `zorg-locale`, and a chrome switcher (EN | FR) on landing/Maker. Path
   prefix `/fr/` is reserved for a later router slice; do not invent Vite
   rewrites here.
3. **CI missing-key gate:** every EN key exists in FR and vice versa (vitest).
4. **Knowledge FR companions** live under `docs/fr/` (`LEARN.md`,
   `PLAYER_GUIDE.md`, `PLAYER_JOURNEYS.md`). The knowledge build emits
   `fr/learn.html`, `fr/guide.html`, `fr/journeys.html` with EN↔FR nav.
   French prose cites the same FR-xx / NFR-xx IDs; if French and the
   spec disagree, **the spec wins**. Honesty / skills / full GAME_SPEC stay
   English until Phase C.
5. Maker “Learn the rules” points at the FR learn page when locale is FR.

## Consequences

- Easier: bilingual Maker chrome and kid/helper copy without engine forks.
- Harder: catalogs must stay complete; new UI strings need EN+FR in the same
  PR or CI fails.
- Out of scope: Phase C honesty/skills bilingual; inventing C / Gunner
  duration / [[FR-4]]; path-prefix routing without a router.
- See [[PLAYER_JOURNEYS]] (optional FR probe), [[LEARN]], [[2026-09-13]].
